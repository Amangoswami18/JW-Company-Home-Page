JW Company Home Page (Frontend)

This project contains a fully-designed, responsive, modern Home Page for thejwcompany.com, built using React with clean UI components and smooth behavior.
Design inspiration follows the structure and flow of dailyobjects.com (without copying any of their assets).

## Features
1. Header

Top Offer Bar

Logo + Brand name

Wishlist, Cart icons with counters

Fully functional Cart Drawer

Fully functional Wishlist Drawer

Clean, minimal UI

Mobile-friendly layout

2. Hero Section

Full-width clean banner

Editable image + text

Modern spacing & typography

3. Categories Section

6 category cards

Image + Title + Short description

Hover effect

Responsive grid

4. New Arrivals Section

Product cards with:

Image

Price

Title

Add to Cart

Wishlist

Smooth layout

Reads data from JSON

5. Featured / Bestseller

Highlight section for a special product

6. Brand Trust Strip

Icons + text

Subtle hover

Clean layout

7. Fully Responsive

Works on:

Desktop

Tablet

Mobile


## Tech Used

React

React Context API

Bootstrap (for utility classes)

JSON data for content

Pure CSS & inline styles (no CSS frameworks)


## Cart & Wishlist Logic-

Cart + Wishlist is stored inside:

src/context/CartContext.js

Add to cart

Remove from cart

Add to wishlist

Remove from wishlist

Works instantly, updates UI without refresh.
